# WeatherTunes ⛅🎶

WeatherTunes is a web application that combines real-time weather data with curated music recommendations. It enhances your mood and environment by suggesting Spotify tracks that match the current weather in your location.

---

## 🌐 Live Demo

Check it out here: [https://weather-tunes-dj39.onrender.com/](https://weather-tunes-dj39.onrender.com/)

---

## 🚀 How to Run Locally

Make sure you have Node.js and npm installed.

```bash
cd client
npm install
npm run dev

This will start the development server at http://localhost:5173.
