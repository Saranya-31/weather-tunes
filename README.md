# WeatherTunes 🎧🌦️

WeatherTunes is a web app that plays mood-based Spotify playlists based on your current weather.

## Features
- Weather detection using OpenWeatherMap API
- Spotify playlist integration
- Responsive frontend built with React + Vite + Tailwind CSS

## How to Run Locally
```bash
cd client
npm install
npm run dev
